# PHOTO LOG

日付と写真だけが並ぶ写真サイト。

## はじめて公開するとき

1. GitHub で新しいリポジトリを作る（Public）
2. このフォルダの中身をぜんぶアップロードする（`.github` フォルダも含める）
3. リポジトリの **Settings → Pages → Source** を **GitHub Actions** にする
4. **Actions** タブで `deploy` が緑になったら、`https://<ユーザー名>.github.io/<リポジトリ名>/` で見られる

## 写真を投稿するとき

`photos/` の中に日付のフォルダを作って写真を入れるだけ。

```
photos/
  2026-11-09/
    01.jpg
    02.jpg
```

- GitHub のサイト上なら「Add file → Upload files」で、ファイル名の欄に
  `photos/2026-11-09/` と打ってからドロップすればフォルダごと作れる
- 写真はファイル名順に並ぶ（01, 02… にしておくと並びを決めやすい）
- アップロードすると1〜2分で自動でサイトに反映される
- スマホの写真をそのまま使うと重いので、長い辺 2000px くらいに縮めておくと表示が速い

## 消すとき

`photos/` から写真やフォルダを削除するだけ。
